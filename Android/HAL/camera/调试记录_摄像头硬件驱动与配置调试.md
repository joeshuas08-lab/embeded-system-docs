# 高级工程师调试记录：摄像头硬件驱动与配置调试

## 功能概述
摄像头硬件驱动调试涉及自动对焦（AF）驱动 IC、ISP39 镜头调优、电源供电配置、图像翻转/镜像、帧率调整和 binning 模式等多个方面。在 RK3576 Android 14 平台中，gc05a2 摄像头模组需配合 CN3927 AF 驱动、RKISP39 tuning 数据进行调试，同时需在设备树和 HAL 层配置正确的电力和信号参数。

## 调试方法

### 1. 摄像头硬件信息检查
```bash
# 查看摄像头设备树节点
cat /sys/firmware/devicetree/base/csi2_dphy*/status
cat /sys/firmware/devicetree/base/i2c*/gc05a2*/status

# 查看 V4L2 设备
v4l2-ctl --list-devices

# 查看摄像头供电状态
cat /sys/kernel/debug/regulator/regulator_summary | grep -i camera
```

### 2. AF 驱动调试
```bash
# 查看 AF 驱动日志
dmesg | grep -E "(af|focus|dw9714|cn3927)"

# 通过 V4L2 控制 AF
v4l2-ctl -d /dev/v4l-subdev1 --set-ctrl focus_absolute=100
v4l2-ctl -d /dev/v4l-subdev1 --set-ctrl focus_automatic_continuous=1
```

### 3. 帧率与分辨率调试
```bash
# 查看支持的格式和帧率
v4l2-ctl -d /dev/video0 --list-formats-ext

# 设置特定帧率
v4l2-ctl -d /dev/video0 --set-parm=25

# 查看当前帧率
v4l2-ctl -d /dev/video0 --get-parm
```

### 4. ISP39 tuning 数据验证
```bash
# 确认 tuning 文件加载
dmesg | grep -i "iq\|tuning\|isp39"

# 检查 json 文件完整性
python3 -m json.tool gc05a2_KYT-11210-V2_default.json > /dev/null
```

## 常见问题及解决方案

### 1. 自动对焦功能异常
**涉及提交：**
- `122709e6a3da` - 添加 CN3927 AF 驱动
- `f9cfdea071e0` - 使能 camera autofocus

**调试步骤：**
1. **确认 AF 驱动注册**：
   ```bash
   # 检查 I2C 设备是否识别
   i2cdetect -y <bus> | grep 0x18  # CN3927 通常地址为 0x18
   
   # 查看驱动注册信息
   dmesg | grep -E "(dw9714|cn3927|vcm)"
   ```

2. **设备树配置**（`myz-rk3576-csi0-gc05a2.dtsi`）：
   ```dts
   &i2c6 {
       gc05a2: camera@37 {
           compatible = "galaxycore,gc05a2";
           reg = <0x37>;
           
           // AF 驱动配置
           lens-focus = <&cn3927>;
           
           // 电源配置
           avdd-supply = <&cam_avdd>;   // commit 2dd7b8e7b0b4
           dvdd-supply = <&cam_dvdd>;
           dovdd-supply = <&cam_dovdd>;
       };
       
       cn3927: cn3927@18 {
           compatible = "dongwoon,cn3927";
           reg = <0x18>;
           rockchip,camera-module-index = <0>;
       };
   };
   ```

3. **HAL 层配置**（`camera3_profiles_rk3576.xml`）：
   ```xml
   <profile name="gc05a2">
       <AF enable="true">
           <mode>CONTINUOUS_PICTURE</mode>
           <driver>CN3927</driver>
       </AF>
   </profile>
   ```

### 2. RKISP39 镜头调优（commit `3aeb48497851`, `d9d9f77d86ca`）

**解决方案：**

```json
    },

        "width": 2592,
        "height": 1944
    },
    "ISP39": {
        // ISP tuning 参数（AEC、AWB、AF、降噪等）
    }
}
```

### 3. 摄像头镜像与翻转（commit `1341363fafce`, `2d68f51eab27`, `762093d664ef`）
**问题：** 预览图像左右或上下颠倒。

**解决方案：**
```c
// gc05a2.c 中配置翻转寄存器
static struct gc052_reg const gc05a2_flip_settings[] = {
    // 水平翻转 (mirror)
    {0x17, 0x13},  // REG_MIRROR
    // 垂直翻转 (flip)  
    {0x17, 0x03},  // REG_FLIP
    // 同时翻转
    {0x17, 0x23},  // REG_MIRROR_FLIP
};
```

**验证方法：**
```bash
# 通过 V4L2 控制翻转
v4l2-ctl -d /dev/video0 --set-ctrl horizontal_flip=1
v4l2-ctl -d /dev/video0 --set-ctrl vertical_flip=1

# 抓图验证
v4l2-ctl -d /dev/video0 --stream-mmap --stream-count=1 --stream-to=test.raw
```

### 4. 帧率配置（commit `b9335c7abd41`, `1be714a48e9d`, `762093d664ef`）
**问题：** 摄像头帧率不符合应用需求（30fps → 25fps → revert 等迭代）。

**调试过程：**
```c
// gc05a2.c 中设置帧率
static const struct gc05a2_mode gc05a2_modes[] = {
    {
        .width = 2592,
        .height = 1944,
        .max_fps = 25,  // 从 30fps 调整为 25fps (commit 762093d664ef)
    },
    // ...
};
```

**帧率验证：**
```bash
# 使用 yavta 测试实际帧率
yavta -c100 -n3 -f NV12 -s 2592x1944 -F /dev/video0
```

### 5. 720p binning 居中（commit `454fb0cce092` → `8bab232f1563` revert）
**问题：** 720p 分辨率下图像未居中，随后该功能被 revert。

**调试要点：**
- 添加了 720p binning central 功能
- 因兼容性问题被 revert（commit `8bab232f1563`）
- 后续若需要可重新实现，需注意 sensor 的 binning/scaling 模式配置

### 6. MIPI CSI 兼容性修复（commit `8b01eecc34c1`）
**问题：** MIPI-CSI 接口在某些配置下无法正常工作。

**调试方法：**
```bash
# 检查 CSI 状态
media-ctl -p -d /dev/media0

# 检查 PHY 配置
cat /sys/kernel/debug/csi2_dphy*/registers
```

### 7. 摄像头 AVDD 供电使能（commit `2dd7b8e7b0b4`）
**问题：** 摄像头因 AVDD 供电未使能而无法工作。

**解决方案：**
在设备树中配置正确的 AVDD 电源：
```dts
&gc05a2 {
    avdd-supply = <&vcc_camera>;  // 使能 AVDD 供电
    avdd-voltage = <2800000>;     // 2.8V
};
```

## 注意事项
1. **AF 驱动兼容性**：CN3927 与 dw9714 兼容，但需确认 I2C 地址和时序。
2. **电源时序**：摄像头供电（AVDD、DVDD、DOVDD）的上下电时序需符合 sensor 规格。
3. **翻转与分辨率**：修改翻转寄存器后需重新确认所有分辨率模式下的图像方向。
4. **帧率与曝光**：降低帧率可能影响自动曝光的响应速度。
5. **tuning 数据管理**：每次修改 tuning 数据需记录版本和对应的镜头型号。
6. **binning 模式**：不同 binning 模式可能影响图像质量，需仔细验证。
