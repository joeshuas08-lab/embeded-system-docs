# DW9714 VCM 自动对焦驱动调试笔记 (RK3576 + GC05A2)

## 概述

DW9714 是用于摄像头模组的 VCM（Voice Coil Motor）驱动芯片，通过 I2C 控制音圈电机推动镜头实现自动对焦。本项目中与 GC05A2 sensor 配合使用。

VCM 驱动 IC: DW9714 (兼容 CN3927)
Sensor: GC05A2
平台: RK3576 + Android 14

---

## 一、驱动架构

### 1.1 驱动层次

```
Application (Camera HAL)
    |
    v4l2_subdev (dw9714)
    |
    I2C 控制器
    |
    DW9714 芯片
    |
    VCM 音圈电机 → 镜头
```

DW9714 驱动实现为 `v4l2_subdev`，通过 `V4L2_CID_FOCUS_ABSOLUTE` control 和 Camera HAL 交互。

### 1.2 关键数据结构

```c
struct dw9714_device {
    struct v4l2_ctrl_handler ctrls_vcm;
    struct v4l2_ctrl *focus;          // V4L2 focus control
    u16 current_val;                   // 当前电流值
    unsigned int max_current;          // 最大电流 (DW9714_MAX_CURRENT = 120mA)
    unsigned int rated_current;        // 额定电流
    unsigned int step_mode;            // 步进模式
    unsigned long move_ms;             // 移动耗时统计
    struct gpio_desc *xsd_gpio;        // XSD 引脚 (用于硬件复位)
    struct regulator *supply;          // 供电 regulator
};
```

## 三、AF 驱动移植 (CN3927)

### 3.1 兼容性说明

提交 `122709e6a3d` (add AF driver CN3927) 添加了 CN3927 VCM 驱动支持。

CN3927 与 DW9714 在寄存器接口上兼容，都是通过 I2C 控制 VCM 线圈电流。区别在于：

| 参数 | DW9714 | CN3927 |
|------|--------|--------|
| 最大电流 | 120mA | 120mA |
| 分辨率 | 10bit (1023 steps) | 10bit (1023 steps) |
| I2C 地址 | 0x18 | 0x18 |
| 高级模式 | 支持 SAC/NRC | 兼容 |

### 3.2 DTS 配置

```c
&i2c4 {
    status = "okay";
    
    dw9714: dw9714@18 {
        compatible = "dongwoon,dw9714";
        status = "okay";
        reg = <0x18>;
        rockchip,vcm-start-current = <0>;
        rockchip,vcm-rated-current = <100>;
        rockchip,vcm-step-mode = <0xd>;
        rockchip,vcm-dlc-enable = <0x0>;
        rockchip,vcm-mclk = <0x0>;
        rockchip,vcm-t-src = <0x0>;
    };
};
```

### 3.3 Camera HAL 使能 AF

BoardConfig.mk:
```makefile
CAMERA_SUPPORT_AUTOFOCUS := true
```

camera3_profiles_rk3576.xml 中对应传感器 profile 需要添加 AF 配置：

```xml
<CamDevie>
    <SupportAutoFocus>true</SupportAutoFocus>
    <VCM>
        <I2cBus>4</I2cBus>
        <I2cAddr>0x18</I2cAddr>
        <VcmType>dw9714</VcmType>
    </VCM>
</CamDevie>
```

## 四、调试工具与方法

### 4.1 确认 AF 状态

```bash
# 查看 v4l2 control 列表
v4l2-ctl -d /dev/v4l-subdev<x> --list-ctrls

# 设置对焦位置（0~1023）
v4l2-ctl -d /dev/v4l-subdev<x> --set-ctrl focus_absolute=512

# 读取当前对焦位置
v4l2-ctl -d /dev/v4l-subdev<x> --get-ctrl focus_absolute
```

### 4.2 I2C 直接验证

```bash
# 读取 DW9714 当前 VCM 位置寄存器
i2cget -f -y <bus> 0x18 0x03 w

# 写入 VCM 位置（测试）
i2cset -f -y <bus> 0x18 0x03 0x0200 w
```

### 4.3 防抖调试

如果 AF 出现抖动或搜步异常：
1. 检查 VCM 供电电压是否稳定
2. 增大 NRC (Noise Reduction Control) 参数
3. 减小 SAC (Shake Avoidance Control) 灵敏度
4. 确认 camera3_profiles.xml 中 AF 场景配置正确

## 五、经验总结

1. **供电要求**：DW9714/CN3927 供电电压 2.7V~3.3V，供电不稳会直接导致对焦异常
2. **I2C 速率**：建议不超过 400kHz，避免 VCM 响应不到位
3. **防抖 vs 速度**：防抖参数越强，对焦速度越慢，需要根据产品需求权衡
4. **IQ 配合**：AF 参数不仅仅在驱动中控制，IQ 文件中的 AE/AWB 策略也会影响 AF 效果（不同光照下的对焦策略）
