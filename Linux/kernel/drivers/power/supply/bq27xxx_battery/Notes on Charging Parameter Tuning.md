# Notes on Charging Parameter Tuning 充电参数调试笔记

## 场景
将原4300mAh电池更换为3900mAh/3.85V电池后，发现充电无法充满或电量显示异常。

## 主要调试内容

### 1. 设备树参数调整
- 取消battery节点注释，更新如下参数：
  - `charge-full-design-microamp-hours = <3900000>;`  // 3.9Ah
  - `energy-full-design-microwatt-hours = <15015000>;` // 3.85V × 3900mAh = 15.015Wh
- 其余参数（如最大充电电流、预充电流、最大充电电压等）保持与原电池一致，除非新电池规格有特殊要求。

### 2. 充电终止电流（charge-term-current-microamp）
- 终止电流设置过高：系统会过早显示100%，但实际电池未充满。
- 终止电流设置过低：实际电池已充满，但系统迟迟不显示100%，充电时间变长。
- 推荐设置为电池容量的2%~5%。
  - 4300mAh × 3% ≈ 129mA
  - 3900mAh × 3% ≈ 117mA
- 换成小容量电池时，终止电流应适当调低。
- 实际调试中，将`charge-term-current-microamp`从66mA提升到100mA，充电显示更合理。

### 3. 其他注意事项
- 充电IC（如bq25890）相关参数需与新电池兼容。
- fuel gauge（如bq27546）如有profile/chemID要求，需同步更新。
- charger-manager节点如有启用，需同步battery节点引用。
- 刷机后建议完全充放电一次，校准电量计。

## 总结
- 更换电池后，需同步调整设备树中的容量、能量、终止电流等参数。
- 终止电流建议按新电池容量的2%~5%设置。
- 其余参数如无特殊要求可保持原值。
- 若遇到电量显示异常、充不满等问题，优先排查终止电流和fuel gauge profile。
