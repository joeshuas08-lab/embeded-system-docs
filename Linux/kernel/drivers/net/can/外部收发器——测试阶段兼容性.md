## 1.1 考虑低速率（5k）速率无法收发，高速路（20k）可以收发，
用以下命令打开can0和can1收发  
ip link set can1 down  
ip link set can1 type can bitrate 5000  
ip link set can1 up  
ip link set can0 down  
ip link set can0 type can bitrate 5000  
ip link set can0 up  
candump can0 -L &  
cansend can1 100#11.22.33.44
