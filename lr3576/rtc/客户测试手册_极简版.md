# 定时休眠唤醒测试手册（客户版）

## 准备（每台设备一次）

```sh
adb root
adb shell pm disable-user --user 0 com.android.providers.calendar
adb shell settings put global location_enable_stationary_throttle 0
adb install AlarmTest.apk
```

## 测试（核心 3 步）

```sh
# 1. 设定 5 分钟定时唤醒
adb shell am broadcast -n com.myir.alarmtest/.AlarmSetReceiver \
  -a com.myir.alarmtest.SET --es delay 300

# 2. 下发休眠
adb shell "echo mem > /sys/power/state"

# 3. 观察：设备休眠约 5-6 分钟后自动唤醒（绝不早于 5 分钟，最多晚 ~1 分钟）
```

## 验收标准

| 项 | 通过 |
|----|------|
| 定时唤醒 | 睡满设定时长后自动醒（不早于设定时间，最多晚 ~1 分钟）|
| 无提前唤醒 | 不早于设定时间醒 |
| 无睡死 | 不超过设定时间 +2 分钟醒 |
| 稳定性 | 连续 10 轮全部通过（每 3 轮重启一次）|
| 产品 app | 用产品自己的 app 设置/下发，唤醒回调正常 |

## 异常时反馈

```sh
su 0 dmesg | grep -E "Resume caused"
```
附输出 + 现象描述。（另可附 `/data/data/com.myir.alarmtest/fired.txt` 判断 alarm 是否真触发）

**注意**：测试期间不要手动修改设备时间（拨时钟会让已设的定时唤醒延后）。
