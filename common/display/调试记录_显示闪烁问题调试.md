# 800x480 MIPI DSI 面板闪烁修复

## 问题现象

- 上电 / 唤醒时屏幕闪烁（不规则条纹）
- 启动过程中 LCD 先亮条纹再正常显示
- 反复 power on/off 每次都会闪

## 排查路径

MIPI DSI 面板闪烁的排查顺序（按经验概率排序）：

```
1. 面板初始化时序不够      → 查 reset-delay / prepare-delay 是否 > 120ms
2. Sleep Out 后缺等待指令  → 查 init sequence 中 0x11 后有没有 05 xx
3. 电压设置不对导致灰阶抖动 → 查 gamma / VCOM 寄存器 (B0/B1/B7/B8)
4. pixel clock 不匹配      → 查 lane-rate 是否配置
5. 硬件供电噪声            → 万用表测 VGH/VGL 纹波
```

**经验法则**：90% 的闪烁是 1 + 2 的组合，3-5 是次要因素。

## 根因分析

### 1. 延时不足（主因）

面板上电需要按顺序经过三个阶段：
```
reset (150ms) → prepare (200ms) → enable (200ms)
```

原来统一用 120ms，但面板要求各阶段至少 150-200ms。120ms 时面板内部电荷泵还没稳定，VGH/VGL 电压不足，液晶分子偏转不完全 → 闪烁。

### 2. Sleep Out 被注释

面板初始化序列省略了 Sleep Out 指令：
```diff
- // 05 78 01 11
+ 05 78 01 11
```
`05` = DCS long write, `78` = 120ms delay, `01` = 1 parameter, `11` = Sleep Out。   
没有这条指令，面板一直处于 sleep 模式就开始接收显示数据 → 闪烁。

### 3. lane-rate 未配置

`rockchip,lane-rate = <400>` 被注释了。RK3576 DSI 的 lane-rate 计算公式：
```
pixel_clock = hactive * vactive * fps * 1.1 ≈ 27MHz
lane_rate = pixel_clock * 24bpp / (2 * 4lane) ≈ 400MHz
```
注释掉之后 DSI 控制器用默认时钟，与 panel 的 pixel clock 不匹配。

### 4. gamma / VCOM 修正

初始化序列中的 B0/B1（gamma 正负校正）、B5/B7/B8/B9/C0（VCOM/VGMP/VGLN 等）也被修改了。   
这些值是面板厂给的 —— 不要自己去"优化"，必须用面板规格书或初始化代码中的值。

## 快速诊断

```bash
# 检查各阶段延时是否生效
dmesg | grep "panel-simple:"
# 预期:
#   panel-simple: prepare delay for 200 ms
#   panel-simple: reset low period for 150 ms
#   panel-simple: delay.init for 120 ms
#   panel-simple: enable delay 200 ms

# 查看当前的 display mode
cat /sys/kernel/debug/dri/0/mode

# 压力测试
for i in {1..100}; do
    echo power_off > /sys/devices/platform/display-subsystem/state
    sleep 2
    echo power_on > /sys/devices/platform/display-subsystem/state
    sleep 3
done
```

## 验证清单

```bash
# 1. 时序参数确认
dmesg | grep panel-simple

# 2. DSI lane rate
cat /sys/kernel/debug/dsi/link_status | grep lane

# 3. 100 次 power cycle 无闪烁
# 目测即可

# 4. log 无 panel 错误
dmesg | grep -i "panel\|dsi\|fail"
```

## 典型失败模式

| 症状 | 最可能原因 | 第一检查点 |
|------|-----------|-----------|
| 上电必闪 | prepare/enable delay < panel 要求 | dmesg 搜 panel-simple 确认延时 |
| 启动过程闪一下后正常 | Sleep Out 被注释掉 | 查 init sequence 里有 05 xx 01 11 |
| 特定颜色下闪烁 | gamma / VCOM 电压错误 | 拿面板厂的初始化序列对比 |
| 低温下闪烁，常温正常 | 延时边缘值，低温裕量不足 | delay 加 50ms 再测 |
| 高频闪烁（类 PWM） | lane-rate 不匹配 | 计算 lane-rate 并配置 |
| 显示偏移或撕裂 | hback porch / hsync 参数不对 | cat /sys/kernel/debug/dri/0/mode |
