# ES8156 音频编解码器移植与调试目录配置

## 问题现象

- 新板卡无声音输出
- tinyplay 播放返回成功但喇叭无声
- 录音无数据

## 排查路径

新 codec 移植三板斧：

```
1. 声卡注册了吗？           → cat /proc/asound/cards
2. mixer control 通了吗？  → tinymix 看有没有对应 codec 的 control
3. 路由配了吗？            → 确认 config_control 的 ctl_name 与驱动注册名一致
```

## 根因分析

### 1. ES8156 不发声根因

ES8156 内部有两个电源域：VDD 给 DAC 供电，SPKVDD 给 Speaker 功放供电。   
DAC Playback Volume 寄存器默认是 0（mute），需要显式设置。   
Speaker 和 Headphone 的 mixer 路径独立，必须分别配置。

**关键参数决策**：
- DAC Volume `191`：ES8156 最大 255，191 约 75% —— 不给最大是因为 EQ 或 APK 可能还有数字增益，留余量
- `ADC Data Select = 1`：选 `Differential` 而非 `Single-ended` —— 取决于硬件 mic 是差分输入还是单端输入，查原理图

### 2. 调试目录迁移背景

Android 14 在 `post-fs-data` 阶段对 `/data` 下的目录权限做了分区隔离。vendor 进程（audioserver、HAL）不能读写在 `/data/` 下直接创建的目录，必须放到 `/data/vendor/` 分区 —— 本质是 `neverallow` 规则收紧。

**典型案例**：audioserver log 写不进去，搜 avc log 看到 `denied { write } for comm="audioserver"`
```
avc: denied { write } for path="/data/crysound/test.log" ...
```
→ 立即查目录是不是在 `/data/` 而不是 `/data/vendor/`

## 移植模板（通用）

添加新 codec 到 Rockchip 音频 HAL 的固定步骤：

1. `audio_hw.c` 的 `SPEAKER_OUT_NAME[]` 添加 `{"rockchipxxx", NULL}`
2. `codec_config/` 下创建 `xxx_config.h`，定义各场景 `config_control` 表
3. `config_list.h` 添加 `#include` + `sound_card_config` 条目
4. 编译烧写后验证 `tinymix` 能看到 codec 的 control

## 验证清单

```bash
# 0. 硬件基础
i2cdetect -y -r <bus> | grep <addr>               # codec 在 I2C 总线上？

# 1. 声卡
cat /proc/asound/cards                              # 出现 rockchipes8156？
cat /proc/asound/pcm                                # playback + capture 设备？

# 2. mixer 通路
tinymix | grep -i es8156                            # control 都注册了？
tinymix "DAC Playback Volume"                       # 不是 0？

# 3. 播放验证
tinyplay /sdcard/test.wav                           # 有声音？

# 4. 录音验证
tinycap /d/tmp/record.wav                           # 有数据？

# 5. 调试目录
ls -laZ /data/vendor/crysound/                      # 标签正确？
ls -laZ /data/vendor/debug/
```

## 典型失败模式

| 症状 | 最可能原因 | 第一检查点 |
|------|-----------|-----------|
| tinymix 看不到 codec control | 声卡 name 不匹配 | dmesg 搜 "ASoC: auto not found" |
| 播放静音但 tinymix 显示正常 | DAC Volume = 0 | tinymix "DAC Playback Volume" |
| 喇叭有嘶嘶声但无音乐 | Speaker Switch 未 on | tinymix "Speaker Switch" |
| 录音文件全 0 | ADC Mux 选择了错误的输入通道 | tinymix "Left PGA Mux" |
| audioserver dlopen 失败 | SELinux 标签是 default_t | ls -laZ 查 context |
