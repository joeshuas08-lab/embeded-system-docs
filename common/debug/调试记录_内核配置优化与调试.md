# 内核配置裁剪

## 背景

Rockchip 的 `rockchip_defconfig` 是所有 RK 平台共享的，里面包含了大量本产品不需要的驱动：
- 各种触摸 IC、G-sensor、磁力计
- 各种 USB 网卡
- 各种充电器
- debug 选项

裁剪的目标：减少内核体积、消除无设备 probe 时的 warning 日志、降低编译时间。

## 裁剪决策

### 哪些可以安全裁剪

**原则**：只有一个驱动对应的硬件、其他同类驱动可以全砍。

| 保留 | 裁剪 | 理由 |
|------|------|------|
| `TOUCHSCREEN_ILI211X` | 其余 8 个触摸驱动 | 产品只用 ILI211X |
| `ICM4260X_ACC` | 其余 15 个 G-sensor | 产品只用 ICM42607 |
| `CHARGER_BQ25890` | SC8551/SC89890/BQ25700/RK817/RK818 | 产品只用 bq25890 |
| `MOTORCOMM_PHY` | RK630_PHY | RK630 是旧 SoC PHY |

### 不能裁剪的

**pm debug 是个坑**：`CONFIG_PM_DEBUG` 关掉后，`/sys/kernel/debug/pm_genpd/` 等节点会消失。如果上层 APK 依赖这些节点来做功耗监控，就不能关。本产品不需要，所以关闭。

### 裁剪工具

```bash
# 查看某个配置是谁/什么 enabled
cd kernel-6.1
make ARCH=arm64 rockchip_defconfig
grep CONFIG_TOUCHSCREEN_PARADE .config   # 还开着？
make ARCH=arm64 menuconfig                # 手动关
make ARCH=arm64 savedefconfig             # 更新 defconfig
```

**注意**：`savedefconfig` 只输出非默认值。所以直接编辑 `rockchip_defconfig` 把行注释掉，再 `make rockchip_defconfig && make savedefconfig` 是最干净的。

## 验证清单

```bash
# 1. 裁剪生效
zcat /proc/config.gz | grep CONFIG_TOUCHSCREEN_ILI211X  # y
zcat /proc/config.gz | grep CONFIG_GSL3673              # 不存在

# 2. 无 phantom probe 错误
dmesg | grep "No device found, probe fail" | wc -l      # 减少

# 3. 内核体积
ls -lh kernel-6.1/arch/arm64/boot/Image                 # 对比裁剪前后

# 4. 功能无损
# 逐个验证：触摸、网络、显示、音频、充电
```

## 典型失败模式

| 现象 | 原因 | 处理 |
|------|------|------|
| 裁剪后某项功能没了 | 关掉了不该关的驱动 | git bisect config 找到哪个选项 |
| savedefconfig 没变化 | 有别的 defconfig 覆盖 | 检查 `ARCH=arm64` 是否设对 |
| menuconfig 里选项看不到 | Kconfig depend on 没满足 | grep Kconfig 查依赖链 |
| dmesg 多了一堆 regulator 错误 | PM_DEBUG 关闭后 regulator debug 节点丢失 | 不影响功能，忽略 |
