# gc05a2 摄像头调试：翻转方向、日志清理、帧率稳定

## 问题现象

- 摄像头预览画面倒置 / 镜像
- kernel log 被 gc05a2 刷屏
- 帧率不稳定，预览卡顿

## 排查路径

```
画面方向不对 → 查 sensor 安装角度 → 改 0x0101 register
日志刷屏      → 找 dev_info 在哪个 path → #ifdef DEBUG 包裹
帧率不稳      → 确认 mclk / data-rate / frame_length → 锁定 25fps
```

## 根因分析

### 1. sensor 翻转方向

gc05a2 通过 `0x0101` 寄存器控制 mirror & flip。bit[0]=1 水平翻转，bit[1]=1 垂直翻转。

```
0x03 = 0000 0011 → 水平和垂直都翻转（默认值）
0x00 = 0000 0000 → 都不翻转（最终配置）
```

**决定因素的硬件条件**：sensor 在 PCB 上的安装角度。如果 lens 朝上安装和朝下安装的翻转配置是相反的。产线不同批次可能安装角度不同，所以有多个 flip 相关的 fix commit。

**快速诊断**：
```bash
v4l2-ctl -d /dev/video0 --set-ctrl horizontal_flip=1
v4l2-ctl -d /dev/video0 --set-ctrl vertical_flip=1
```
通过 v4l2-ctl 在线切换翻转，不需要编译烧写就能确认最终值。

### 2. 帧率策略迭代

gc05a2 的帧率由 VTS（Vertical Timing）寄存器控制。迭代历史：
- 最早尝试 30fps → 发现 sensor 输出不稳定（exposure window 不够）→ revert
- 尝试 720p bining → 图像分辨率降低但客户不接受 → revert
- 尝试过锁 25fps + 1080p = 稳定方案

**判断帧率问题的方法**：
```bash
# 确认 sensor 输出的帧率
cat /sys/kernel/debug/csi2/status | grep fps
media-ctl -p -d /dev/media0 | grep -i fps
```

## gc05a2 调试信息清理方案

驱动的 `dev_info` 在 release 版本中必须移除。gc05a2 的清理方式不需要修改每个调用点，用宏统一覆盖：

```c
#ifndef DEBUG
#undef dev_info
#define dev_info(dev, fmt, ...)  do { } while (0)
#endif
```

**原理**：release 编译不定义 `DEBUG`，预处理器将所有 `dev_info` 替换为空语句。如果需要调试某个具体问题，在文件开头 `#define DEBUG` 即可恢复。

**何时需要调试输出**：
```bash
# 启动时动态开启（不需要重编译）
echo "file gc05a2.c +p" > /sys/kernel/debug/dynamic_debug/control
# 前提：驱动中的 dev_info 要改为 dev_dbg
```

## 验证清单

```bash
# 0. sensor 通信
i2cdetect -y <bus> | grep gc05a2  # 有 device？
dmesg | grep gc05a2                # probe 成功？

# 1. 画面方向
v4l2-ctl -d /dev/video0 --all | grep -i flip

# 2. 帧率
media-ctl -p -d /dev/media0 | grep -i "code:.*fmt"
cat /sys/kernel/debug/csi2/status

# 3. 日志整洁度
dmesg | grep gc05a2 | wc -l       # release 应为 0

# 4. ISP json 生效
cat /vendor/etc/camera/cam_overrides.json | grep gc05a2
```

## 典型失败模式

| 症状 | 最可能原因 | 第一检查点 |
|------|-----------|-----------|
| 预览方向反 | 0x0101 寄存器值不对 | v4l2-ctl --set-ctrl 在线测试 |
| 图像花屏 | MIPI data-rate / clock 不对 | dmesg 搜 "csi2: lane" |
| sensor probe 失败 | 供电 / I2C 不通 | i2cdetect + 万用表测电压 |
| kernel log 溢出 | dev_info 未在 release 中禁用 | grep dev_info gc05a2.c |
| 帧率只有 15fps | frame_length 未匹配 pixel clock | 算 VTS = vt_clk / (hts * fps) |
| json 配置不生效 | cam_overrides.json 路径或格式错 | dumpsys media.camera 查 provider |
