# bq25890 充电器移植、电量计配置与关机快充

## 问题现象

- 插入充电器不进充电状态
- 充电电流偏小/偏大（发热严重）
- 电池电量跳变（30%→50%→20%）
- 关机后电池不进充

## 排查路径

充电问题排障顺序：

```
1. 插充电器，Power Supply 设备有反应吗？ → cat /sys/class/power_supply/*/uevent
2. 电压电流读到了吗？                     → dmesg | grep bq25890
3. 中断触发了？                           → cat /proc/interrupts | grep charger
4. 关机充不进？                          → 查 shutdown callback 有没有设充电参数
```

## 根因分析

### 1. 充电不进 / 不识别

bq25890 的 VBUS 检测依赖 Type-C 控制器（usbc0）的 PD 协商结果。  
如果 `ti,usb-charger-detection = <&usbc0>` 未正确关联，PD 协商完成后充电器驱动不会收到通知，`IINLIM` 保持默认 100mA，表现为充不进。

**识别逻辑链**：
```
Type-C 插入 → TCPM PD 协商 → usbc0 通知 bq25890 → bq25890 解析 PDO → 设置 IINLIM/ICHG
```
任一环节断掉 → 充电不工作。最常见的是 dts 中 extcon 或 phandle 关联错误。

### 2. 充电电流设计决策

硬件最初设 1.6A，但温升测试发现 bq25890 和电池温升超过 45°C 安全阈值。  
最终钳位到 1.0A（`68d43560dee`），代码和 dts 双重限流：

```c
// 驱动层硬限幅：不管 PD 协商来多大电流，最高 1A
if (cur > 1000000)
    cur = 1000000;
```

```dts
// dts 层默认电流也降到 1A
ti,charge-current = <1000000>;  /* 1.0A */
```

**经验**：不要只改 dts。PD 协商可能协商出更大电流，驱动层不做钳位的话 dts 的默认值会被覆盖。

### 3. 电量跳变的原因

bq27546 电量计依赖电池内阻表和 OCV 表来估算电量。如果 `charge-full-design-microamp-hours` 和 `factory-internal-resistance-micro-ohms` 与实际电池不符，电量计的计算结果会严重偏离。

**判定方法**：
```bash
# 对比设计容量 vs 实际充入容量
cat /sys/class/power_supply/battery/charge_full_design
cat /sys/class/power_supply/battery/charge_counter
# 如果 charge_counter 充满后远小于 charge_full_design → 容量参数设置错误
```

**参数更新历史**：
- 最初 8000mAh（默认值，不匹配）
- `0ebb917d436` 改为 3500mAh（实际电池容量）
- `dbb38cfc9c8` 更新为 3900mAh 电池适配

### 4. 关机快充

关机充电的难点：系统关机时 Linux 设备驱动的 shutdown 顺序不确定。bq25890 的 shutdown 中需要：

1. 设置关机充电参数（IINLIM、VREG、ICHG）
2. 禁止 vsys 关断
3. Type-C 控制器也要保持 VBUS（husb311 的 set_vbus(true)）

**失败模式**：关机后插充电器没反应 → 检查 husb311 的 shutdown 有没有调用 `husb311_set_vbus(true)`。只配 bq25890 不配 husb311 等于没配。

## 充电参数速查表

| 参数 | 原始值 | 最终值 | 修改原因 |
|------|-------|--------|---------|
| ti,charge-current | 1.6A | 1.0A | 温升超标，钳位 |
| ti,termination-current | 66mA | 88mA | 提前终止防过充 |
| ti,battery-regulation-voltage | 4.4V | 4.4V | 未变 |
| ti,boost-max-current | 1.6A | 1.75A | OTG 输出能力提升 |

## 验证清单

```bash
# 0. 充电器硬件
cat /sys/class/power_supply/usb/online               # 1 表示插入
cat /sys/class/power_supply/usb/present

# 1. 充电状态
cat /sys/class/power_supply/battery/status           # Charging?
cat /sys/class/power_supply/battery/capacity         # 电量?
cat /sys/class/power_supply/charger/uevent           # 电压电流?

# 2. 关机充电
adb reboot -p                                         # 关机
# 插充电器 → 观察指示灯 + 充电动画

# 3. 温升监控
cat /sys/class/power_supply/battery/temp             # 典型 25-45°C
cat /sys/class/thermal/thermal_zone*/temp

# 4. 电流限制验证
dmesg | grep "bq25890_set_pd_param"
```

## 典型失败模式

| 症状 | 最可能原因 | 第一检查点 |
|------|-----------|-----------|
| 插充电器不进充电 | extcon/phandle 关联错误 | dmesg 搜 "bq25890: PD" |
| 充电电流异常小 | PD 协商失败，IINLIM 走默认 100mA | cat charger/input_current_limit |
| 充到 80% 就停 | termination current 太大，提前终止 | cat charger/charge_term_current |
| 电池从 50% 跳到 20% | battery 容量参数与实际不符 | cat battery/charge_full_design |
| 关机不充电 | husb311/bq25890 shutdown 未配 | 查 shutdown callback 代码 |
| 充电发热严重 | 电流未钳位 | 检查驱动中 cur 钳位逻辑 |
| 插充电器死机 | 充电中断冲突，GPIO 被其他驱动占用 | cat /proc/interrupts 查 charger irq |
